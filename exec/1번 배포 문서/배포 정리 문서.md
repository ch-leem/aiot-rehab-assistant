## 1) 사용한 JVM, 웹서버, WAS, 제품 종류 및 버전

본 프로젝트는 Docker 기반 멀티 컨테이너 환경에서 실행된다.

### 개발 및 실행 환경

```text
- OS: Ubuntu 20.04 LTS (AWS EC2)
- Container: Docker, Docker Compose
```

### Backend

```text
- Java: OpenJDK 17
- Spring Boot: 3.2.x
- Gradle: 8.x
- WAS: Embedded Tomcat (Spring Boot)
```

### Realtime / Ingest Server

```text
- Language: Python 3.10
- Framework: FastAPI
```

### Database / Cache

```text
- Database: PostgreSQL 15 + TimescaleDB
- Cache / Streaming: Redis 7.x
```

### Web Server

```text
- Reverse Proxy: Nginx
- HTTPS: Certbot (Let’s Encrypt)
```

### Development IDE

```text
- IntelliJ IDEA 2024.x
- VS Code
```

## 2) 빌드 시 사용되는 환경 변수

본 프로젝트는 민감 정보 보호를 위해 **환경 변수(.env)** 기반으로 설정된다.
실제 값은 저장소에 포함되지 않으며, `.env.example` 파일을 기준으로 설정한다.

추가로 프론트엔드 내부에 넣는 `.env.frontend.example`가 있다.

#### Database

```text
DB_HOST
DB_PORT
DB_NAME
DB_USERNAME
DB_PASSWORD
```

#### Redis

```text
REDIS_HOST
REDIS_PORT
REDIS_PASSWORD
```

#### External Service

```text
OPENAI_API_KEY
```

## 3) 배포 시 특이사항

```text
- Docker Compose 기반으로 모든 서버(iot-api, user-api, ingest-api, redis, db, nginx)를 실행함
- Nginx를 통해 외부 요청을 내부 서비스로 reverse proxy 처리
  - /iot-api → backend-iot
  - /api/user → backend-user
- HTTPS 인증서는 Certbot을 통해 발급 및 자동 갱신
- 최초 실행 시 Hibernate ddl-auto=update 설정으로 DB 테이블 자동 생성
- 방화벽에서 80, 443 포트 개방 필요
```

## 5) 빌드 및 실행 방법

### 1) 빌드 배시


```bash
# 1. GitLab 저장소 클론
git clone <GitLab Repository URL>
cd <프로젝트_루트_디렉토리>

# 2. Backend / Ingest 환경 변수 설정 (프로젝트 루트)
cp .env.example .env
# .env 파일에 DB, Redis, API Key 등 환경 변수 값 입력

# 3. Frontend 환경 변수 설정
cd frontend
cp .env.frontend.example .env
# .env 파일에 VITE_ 접두어 환경 변수 값 입력
cd ..

# 4. Docker 컨테이너 빌드 및 실행
docker-compose up -d --build

# 5. 서비스 확인
https://<도메인 주소>

```

### 2) EC2 실행 사용자 및 권한

#### 실행 사용자
- 본 프로젝트는 EC2 인스턴스에서 docker 실행 권한이 있는 사용자로 실행되고 서비스 계정(appsvc)을 기준으로 실행되었다.
보안을 위해 일반 사용자와 서비스 실행 계정을 분리하였으며,
Docker 및 배포 관련 작업은 appsvc 계정을 통해 수행한다.


#### 권한 관련 유의사항
- Docker 명령어 실행을 위해 실행 사용자는 docker 그룹에 포함되어야 함
- docker 그룹에 포함되지 않은 경우 sudo 권한 필요
- appsvc 계정은 docker 그룹에 포함되어 있음
- 서비스 실행 시 root 계정은 사용하지 않음

#### 참고 명령어 (선택)
sudo usermod -aG docker <username>
newgrp docker
